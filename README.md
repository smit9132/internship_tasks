# Internship Projects

This repository contains software development internship projects.

## Projects

### Task 1 — LeadFlow: AI CRM Automation

A full-stack lead-management CRM built with vanilla JavaScript, Express, MongoDB/Mongoose, and an optional n8n webhook workflow.

- [Project guide, setup, API reference, and testing](./task-1-leadflow/README.md)
- [LeadFlow application source](./task-1-leadflow/)

LeadFlow runs locally by default. No remote repository or external service is configured by this README.

### Task 2 — TrackWise: Personal AI Assistant

A local personal productivity assistant for expenses, habits, and tasks.

- [TrackWise setup and usage guide](./task-2-trackwise/README.md)
- [TrackWise application source](./task-2-trackwise/)

### Task 3 — EventSync: Event Management System

A full-stack event management platform for discovering events, managing attendee registrations, and administering users and events.

- [EventSync setup, API, security, and deployment guide](./task-3-eventsync/README.md)
- [EventSync application source](./task-3-eventsync/)

A local-first browser face-detection monitoring demo with explicit camera consent, configurable presence rules, a timestamped event feed, and optional MongoDB session metadata.

- [Vision Guard setup, privacy, API, and deployment guide](./task-4-vision-guard/README.md)
